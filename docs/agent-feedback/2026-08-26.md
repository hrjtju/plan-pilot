## 场景
日程调度生成。

## Agent 实际做了什么
可能排出早于当前时间的块，或对已过时的固定任务直接处理。

## 期望
不得排入任何早于当前时间的块；已过时间的固定任务作为问题返回，请用户确认是否顺延。

## 理由
历史会话明确要求 "NO PAST SCHEDULING"：已过时间块不排，固定块顺延需确认。

## 场景
代码审查结论。

## Agent 实际做了什么
声称"审查完成，未发现 bug"，但未覆盖跨模块调用与边界场景。

## 期望
审查结论需覆盖逻辑、跨模块调用、边界场景三方面，并给出证据。

## 理由
历史会话出现"审查完成，未发现 bug"后被用户继续挑出问题，说明结论过于武断。

## 场景
git 拉取远端更新。

## Agent 实际做了什么
git fetch 写 .git/FETCH_HEAD 被沙箱拦截，先失败一次再请求授权。

## 期望
涉及写 .git 的操作（fetch/pull/checkout 等）直接请求授权，不先失败一次。

## 理由
历史会话出现 "error: cannot open '.git/FETCH_HEAD': Permission denied"。
